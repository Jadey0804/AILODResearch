# AILOD MVP 当前项目状况（大白话版）

**日期：2026-08-30**<br>
**分支：`phase-7-visual-demo`**<br>
**当前阶段：Phase 7E 已完成主地图验收并本地封板；尚未 push。**

## 一句话总结

后台大规模 NPC 社会模拟和实验工具已经基本完成，UE 中也已经能看到地图、NPC、时间 UI、LOD 切换和望远镜远距 Lift。当前最主要的剩余工作不是继续增加功能，而是完成 Phase 7F 总验收、采集论文正式实验数据，并把占位表现整理到不会明显穿帮的程度。

## 已完成的核心部分

### 1. 大规模模拟底座

- 居民身份、职业、资源、住房、维修、政策、行动和事件等核心流程已经具备。
- 大量远处居民按群体推进，玩家附近最多提升 50 个真实居民，不需要让全部人口逐人高频思考。
- ResidentID、HomeID、任务进度和资源预约能够在聚合、解聚合和回访后保持连续。
- 20k 默认规模与 100k 工程压力检查已经跑通；v1.9 已冻结并取得正式实验资格。

### 2. 实验基础设施

- 已能固定 Seed、记录清单、回放同一结果、检查硬错误，并分别统计模拟阶段成本。
- 已有准确性、性能和自动回归流程，可以支撑后续正式实验。
- 以前运行的 Development、Pilot 和工程压力检查只能证明系统可运行，不能代替论文最终统计数据。

### 3. UE 可视化 Phase 7-0 到 7E

- 可视化、UI、Actor、PCG 和地图只读取模拟，不会成为第二套权威状态。
- 已完成固定世界布局、空间格子查询、World Partition、导航、玩家移动、俯视相机和功能型 UI。
- 已完成低层代理、最多 50 个完整 NPC Actor、点击查看居民和主地图 revisit 连续性修复。
- 已完成望远镜视角、远距候选、持续观察、远处格子临时加载、权威 Lift 和同一 ResidentID 追踪。
- 主地图 PCG 已换用房屋、工厂和三种树模型，并重新生成；道路正常，当前模型位置已完成第一轮贴地调整。

## 当前还不完善的地方

1. 低层 NPC 目前仍是静止细圆柱代理，玩家能够看出它与完整 NPC 的差别；最终应换成外观一致、成本更低的移动表现。
2. 望远镜 Pitch 调整后，准星与实际被选中的 NPC 位置有轻微偏差。
3. PCG 新模型对应的 HLOD 尚未重建；近景新模型已生成，但远景代理仍需在 Phase 7F 统一更新和检查。
4. 地图和 UI 仍偏功能灰盒，不是完整商业游戏画面。

## 还没有完成什么

1. **Phase 7F：**完整回归、Game Development、快速移动和反复望远镜测试，以及有画面 FPS、帧时间、生成/加载尖峰、Draw Call、显存和内存测量。
2. **视觉 LOD 防穿帮：**让低成本居民和完整 NPC 在玩家眼中尽量一致，并保证接近或交互时无感升级。
3. **正式实验：**按冻结方案执行正式 Shipping 多轮实验，整理准确性、性能和一致性数据。
4. **论文收尾：**论文 v1.0 已有结构和初稿，但 Results、Discussion、图表、真实数据、引用核对和最终格式仍需用正式实验结果补齐。

## 当前完成度判断

- 核心模拟与实验工具：约 90%。
- UE 功能演示：约 75%。
- 正式实验与数据分析：约 25%。
- 毕业论文：约 45%。
- 整个毕设综合：约 70%。

这里的 70% 不是按代码行数计算，而是按最终能否答辩来估算。最难的模拟架构已经完成；剩余工作数量没有前面多，但正式数据、性能证据和论文结果章节都是答辩必需品，不能省略。

## 最短完成路线

1. 进入 Phase 7F，先完成正确性总回归和有画面性能采集。
2. 只修会影响演示或数据可信度的问题，包括低层代理穿帮、准星偏差和新 PCG 模型的 HLOD。
3. 冻结代码和参数，运行正式实验。
4. 自动生成表格和图表，把真实结果填入论文 Results 与 Discussion。
5. 做最后一次可复现性、引用、格式和答辩演示检查。

## 最后判断

这个项目已经不是“能不能做出来”的阶段，而是“怎样把已有系统变成可信的实验结果和可答辩成品”的阶段。下一步不应继续扩功能，应开始 Phase 7F 和正式数据收口。
